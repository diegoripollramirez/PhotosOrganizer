#  Los nombres de esta lista NO se guardan como etiqueta de álbum
#  al mover las fotos a la maestra (ni cuentan como "álbum" al
#  elegir qué copia de un duplicado conservar).

#  · Un nombre por línea, sin distinguir mayúsculas.
#  · Se compara con el nombre COMPLETO de la carpeta.
#  · Comodines:  *  cualquier texto
#                ?  un carácter cualquiera
#                [0-9]  un dígito
#  · Las líneas que empiezan por # son comentarios.
#
#  Puedes añadir o quitar nombres libremente. Por ejemplo, si
#  quieres que "WhatsApp" sí se guarde como etiqueta, borra esa
#  línea (o ponle # delante).
